# TaskFlow Lite

## Overview

TaskFlow Lite is a responsive task management web application built using vanilla JavaScript, HTML, and CSS.

The application allows users to:
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks
- Store tasks using localStorage
- Toggle dark/light mode

The project demonstrates DOM manipulation, modular JavaScript architecture, localStorage persistence, and responsive UI design.

---

## Features

### Task Management
- Add new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Mark tasks as completed

### Filters
- View All Tasks
- View Active Tasks
- View Completed Tasks

### Data Persistence
- Tasks are stored in browser localStorage
- Data remains after page refresh/restart

### UI Features
- Responsive design
- Dark/Light mode toggle
- Task statistics counter
- Empty task state
- Modern dashboard interface
